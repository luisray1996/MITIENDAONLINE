# AKUMA STORE

Tienda web oscura/fucsia/morada para vender polos.

## Cómo abrir
1. Abre `index.html` con Chrome.
2. No necesitas instalar nada.
3. Cambia el número de WhatsApp en `js/app.js`:
   `const WHATSAPP_NUMBER = "912132881";`

## Cómo poner tus propios polos
Reemplaza los SVG de `assets/products/` por tus imágenes JPG/PNG y cambia las rutas y nombres/precios en `js/app.js`.

## Funciones incluidas
- Catálogo y filtros
- Buscador
- Ficha de producto
- Tallas y colores
- Cantidad
- Favoritos con localStorage
- Carrito con localStorage
- Total en soles
- Pedido por WhatsApp
- Diseño responsive para celular
- Menú móvil
